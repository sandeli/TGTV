# 本机订阅导入说明

TGTV 是一个不包含内置频道源的播放器。首次启动时列表为空；用户可以导入自己的订阅 URL。频道列表由该 URL 提供，频道可用性取决于订阅与网络。

## 手机扫码导入

1. 在电视上打开「设置 → 订阅链接 → 二维码」。
2. 手机和电视连接同一局域网，扫码进入空白输入页。
3. 手动粘贴播放列表 URL 并提交。新链接会替换本机已保存的订阅。

支持 M3U、TXT（`#genre#`）、XSPF，也兼容 JSON 列表。App 不会预填固定地址。

二维码直接打开局域网导入页，不使用配对令牌；服务仅在二维码页打开期间运行，只提供页面和播放列表导入接口，退出页面后停止监听。请仅在可信网络使用。

## 数据保存与网络行为

订阅 URL 保存在本机应用设置中；下载的播放列表与 EPG 缓存在本机应用私有持久目录。它们不上传到云端或远程控制后台。升级时，旧版用户订阅缓存会迁移到持久目录；应用不再读取旧版内置频道缓存。

网络请求限于用户自己提供的订阅地址、用于 EPG 的数据源和正在播放的流。不存在远程命令、远程更新、远程设置下发或云端保存订阅的接口。

## 反馈频道问题

反馈时请避免粘贴包含账号、密码或访问令牌的完整订阅 URL。可以提供频道名、现象、地区/网络类型和 App 版本；在本仓库的 Issues 页面提交即可。
